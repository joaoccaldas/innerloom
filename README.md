# InnerLoom

Financial planning and cost analysis tool with staff cost breakdowns, P&L summaries, cash flow tracking, and KPI dashboards.

## Features

- Staff cost calculator with tax and burden rates
- Category-based cost input
- Financial dashboard with P&L, cash flow, and KPIs
- SEK currency formatting

## Getting Started

Open `index.html` in a browser.
